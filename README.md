# AI Learning Marketplace (DevOps Easy Learning)

A Udemy-style, multi-instructor marketplace for AI and DevOps courses: students discover, preview, buy and study courses;
instructors publish and get paid through Stripe Connect; a super admin runs the platform.

**Status:** assessment and plan, awaiting the owner's approval: see [docs/ASSESSMENT.md](docs/ASSESSMENT.md).
Research notes: [docs/research/](docs/research/).

Rules for anyone working here: everything for this marketplace lives in this repository; use only what is needed from the
reference projects; never copy secrets; no push, merge or deployment beyond local without the owner's approval.
